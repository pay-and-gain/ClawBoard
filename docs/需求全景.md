## 一、一句话总览

你要的不是"一个剪贴板工具"，而是三样东西叠在一起：

1. **一个能日常用的剪贴板历史 + 常用语悬浮面板**（这是产品本体）
2. **一次完整的软件工程交付演练**（需求→设计→实现→测试→打包→双语言版本→讲解材料，这是给老师看的）

## 三、按主题归类（你真正关心的 12 类）

### ① 产品本体：剪贴板历史
- 悬浮面板，复制即入库，重复复制不重复建条目（只 `+copy_count`）
- 上限控制、裁剪、清空；**裁剪和清空都跳过收藏项**（参考 Ditto / CopyQ）
- 捕获长度上下限，滤掉单字符噪声与超长正文
- 去重、历史搜索

### ② 产品本体：常用语
- 分组管理、命名、编辑、删除
- **拆词**：一段文字拆成多条常用语
- 与剪贴板历史同一套搜索与列表

### ③ 数据可靠性
- `schema_version` 版本化迁移（1→2→3），幂等
- 迁移前自动备份 `.bak`，失败自动回滚
- 老数据缺字段全部 `setdefault` 兜底，估算时间标记 `is_estimated=1`（界面显示"约"）
- 写入统一「先 `.tmp` 再 `os.replace`」，防半截文件

### ④ 时间语义（F0）
- `created_at` / `updated_at` / `last_used_at` **三个语义严格分离**
- 默认**不显示**在列表，悬停出相对时间，右键「查看详情」看完整三个时间
- 重复复制只刷 `updated_at`，粘贴只刷 `last_used_at`，**`created_at` 永不改写**
- 时钟回拨保护（用 seq 兜底 + 记日志）

### ⑤ 来源溯源（F1）
- 前台窗口 → PID → 进程名 → 列表副标题显示
- 支持 `app:` 搜索，中文/模糊匹配
- 抓到自己的界面或空值 → 50ms 后重试一次

### ⑥ 隐私安全（这一块是你没点名但最值钱的）
- **遵守 Windows 官方「别记录我」标记**：读 `ExcludeClipboardContentFromMonitorProcessing` 与 `CanIncludeInClipboardHistory`（值 0）→ 命中整条跳过。这是 KeePassXC / 1Password / Bitwarden 的标准信号
- **程序忽略名单**（通配符）+ **窗口标题忽略名单**（正则），已预置 keepass / 1password / bitwarden / lastpass
- 标题含"密码 / 银行卡 / 登录"一律不存
- 敏感内容识别 + 打码显示，导出前红色警示

### ⑦ 搜索能力（F3）
- 高级语法：`time:` / `app:` / `type:` / `size:` / `is:` / `-排除`
- 多词 AND、多词高亮
- 语法错误 → 红框提示，**绝不崩溃**
- 搜索历史 10 条 + 语法帮助面板

### ⑧ 工具箱（F4 / F5）
- **27 项文本变换**：编解码、大小写、行处理、哈希（MD5/SHA1/SHA256）、JSON 格式化…左选右预览，可复制 / 存为新条目 / 覆盖原条目（覆盖保留 `created_at`）
- **批量导出**：多选（Ctrl/Shift/Ctrl+A）→ TXT / CSV（带 BOM 防 Excel 乱码）/ JSON / Markdown

### ⑨ 粘贴可靠性（F6 + v1.4.0）
- 粘贴为纯文本：剥 HTML 标签与实体，`<br>/<p>/<li>/<td>` → 换行/制表符
- **发键前先抬掉所有按着的修饰键**（解决"有时粘贴没反应"的真因）
- `AttachThreadInput` 绕前台锁定 + **轮询等焦点真的切过去**再发键
- `SendInput` + 扫描码替代废弃的 `keybd_event`
- `Ctrl+1..9` / `Ctrl+0` 快速粘贴，按住 Ctrl 时行首显示序号
- 粘贴时去掉首尾空白（默认开，可关；**中间行缩进保留**）

### ⑩ 交互与窗口（你反馈最密集的一块）
- 滚轮上下滑动，一格 3 行，触控板高精度滚轮也能用
- 右侧 8px 自绘细滑动条（悬停变亮、拖动变蓝、不满屏只留淡轨道）
- 双击折叠热区 = 整条标题栏（59%），折叠后**贴到所在屏幕右下角**
- 窗口永远完整落在某一个显示器内，跨屏缝隙也能拉回
- 面板最小尺寸 280×340（按 DPI 换算，本机 125% 下实际 349×424）
- 托盘图标 + 全局热键（Ctrl+Shift+V，被占用自动降级）+ 单实例互斥
- 明确的退出路径：设置里选隐藏/退出、Ctrl+Q、设置面板红色退出按钮、托盘「重置位置」
- 靠边自动隐藏（默认关）、开机自启（默认关）

### ⑪ 个性化
- 亮 / 暗双主题
- **自定义背景色**，其余配色自动推导（面板/卡片/边框按深浅乘系数，文字按亮度自动选深或浅）
- 内容自适应：按类型（路径/URL/邮箱/颜色/JSON/代码/多行/文本）自动换字体、换颜色、换徽章图标

### ⑫ 交付与工程化
- Python 版打包 exe（12.6 MB）
- **C 语言版**（VS 2026，2568 行，205 KB，内存约 15 MB，零警告），自写迷你 JSON 解析器，**能直接读 Python 版的数据文件**
- Python 版精简（滚动刷新 -22%）
- 「ClawBoard 制作思路.docx」讲解文档
- **17 个自测脚本**，每轮改动都跑回归

## 五、反复出现的四类根因（跨版本重复踩）

| 根因 | 出现版本 | 本质 |
|---|---|---|
| **pack 空间分配 / 顺序** | v1.3.3、v1.4.2、v1.4.3、v1.4.5 | 固定尺寸控件必须比带 `expand` 的先 `pack`；`pack_forget` 后重 pack 只能排队尾 |
| **Tk 事件不冒泡** | v1.3.2、v1.4.2 | 滚轮、双击必须绑到每个子控件，绑父容器等于没绑 |
| **DPI 未声明导致测量失真** | v1.4.1 | 读窗口/屏幕坐标前必须 `SetProcessDpiAwareness(2)` |
| **压测/自测路径隐式写盘** | v1.4.0 | 光加注释没用，`__init__` 里的隐式 `save()` 会绕过去 |

## 六、明确"没做"或"降级"的部分（不假装实现）

| 你的需求/我的建议 | 实际处理 | 原因 |
|---|---|---|
| SQLite + SQL 索引 | 用 JSON + `schema_version` 迁移 + 内存谓词过滤 | 项目原本就是 JSON 单文件，为"不重写"保留 |
| 图片 / 文件剪贴板 | 只监听文本（`CF_UNICODETEXT`） | 定位是纯文本工具 |
| 进程图标位图 | 显示进程名 + 类型/大小徽章 | 提 HICON 要 GDI+ 编码成 PNG，收益不抵复杂度 |
| 时间分组标题行 | 改为 `time:` 语法筛选 | 虚拟列表固定行高，插不等高标题行会破坏虚拟化 |
| CopyQ 的大文本外置存储 | 未做 | 只有文本条目，JSON + 原子替换够用 |
| Ditto 的改全局前台锁定超时 | 改用 `AttachThreadInput` | 原方案会影响系统所有程序 |

**我在 v1.4.3 给你提过、你尚未要求做的建议**：
备份轮转（`.001/.002`）、`crash.log` 上限、正则搜索模式、置顶(pin)与收藏分开、拖拽排序、图片/文件剪贴板扩展。
其中**双屏不同缩放时 Tk 不响应 DPI 变化**是 tkinter 的已知局限，改不了。

## 七、你需求里最"值钱"的三条

如果只挑三条，是你这三个决定让这个项目从"课程作业"变成了"能真用的工具"：

1. **「去 GitHub 读 3 款高星项目的源码」** —— 这一步引入了 Windows 官方隐私标记、修饰键抬升、`AttachThreadInput`、快速粘贴、收藏豁免。这些是看文档学不到的实战经验。
2. **「再出一个 C 语言版本」** —— 逼出了自写 JSON 解析器、BCrypt 哈希、GDI 自绘，也让"数据文件两版互通"成为可能。
3. **持续报真实问题** —— 后面 5 个版本全靠你的反馈驱动，且暴露的全是跨平台 GUI 开发里最难的几类坑。
