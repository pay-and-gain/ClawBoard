使用指南

Usage guide

运行

Run

python ClawBoard.py     # 需要 Python 3 + tkinter# requires Python 3 + tkinter

或解压便携包运行 ClawBoard.exe，无需安装 Python。可写便携目录的数据与 exe 同层；目录不可写时回退到 %APPDATA%\ClawBoard，以托盘“关于”显示的路径为准。

Or extract the portable package and run ClawBoard.exe; Python is not required. Writable portable folders keep data beside the exe. An unwritable folder falls back to %APPDATA%\ClawBoard; check the actual path in About.

触发词仅对独立标准 US 键盘布局启用；中文输入法仍可正常复制、搜索和点击常用语。向管理员窗口输入时会保留复制并提示手动 Ctrl+V。升级前备份 JSON 和整个图片目录。

Triggers require a separate standard US keyboard layout. Chinese IMEs still support normal copy, search and phrase clicks. Elevated targets fall back to copying and manual Ctrl+V. Back up the JSON file and complete image folder before upgrading.

数据与安全

Data & safety

  • 数据存 ClawBoard数据.json，纯文本、可备份、可迁移
  • 写文件采用「先写临时文件再原子替换」，不会写一半变成坏文件
  • 版本升级前自动备份（保留最近 3 份）；读取时逐字段校验
  • Python 与精简 C 实现保持共享数据契约，功能范围不同；切换前先退出并备份
  • Data lives in ClawBoard数据.json — plain text, easy to back up and migrate
  • Writes go to a temp file and are atomically swapped in — no half-written file
  • Automatic backup before schema upgrades (keeps the last 3); per-field validation on read
  • Python and the smaller C implementation share a data contract, with different feature sets; quit and back up before switching

设计思路要点

Design highlights

  • 先能跑 → 再跑得稳 → 最后才堆功能：分三批做，第一批就能日常使用，后面每批都在可用的基础上加
  • 本地工作流：把历史、常用语、搜索和粘贴放在一个面板中，更新检查可关闭
  • 实现取舍：Python/tkinter 作为当前完整发布，C/Win32 保留精简实现和数据兼容参考
  • 有界界面工作：虚拟列表复用可见控件，后台查询与图片处理通过主线程队列交付结果
  • 三道数据保险：原子写 + 升级前备份 + 逐字段校验
  • Make it run → make it stable → then pile on features: three batches; the first is already usable daily
  • A local workflow: history, phrases, search and paste in one panel, with optional update checks
  • Implementation tradeoff: Python/tkinter is the current full release; C/Win32 remains a smaller implementation and compatibility reference
  • Bounded UI work: visible widgets are reused, while background queries and image processing deliver results through the main-thread queue
  • Three data safeguards: atomic writes + pre-upgrade backup + per-field validation
