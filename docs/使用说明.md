# ClawBoard 使用说明（v2.1.0）

零第三方依赖的 Windows 10/11 悬浮剪切板 & 常用语面板，仿手机端搜狗/酷狗输入法的剪切板。
只用 Python 标准库 tkinter + ctypes，不装任何包。

## 三种运行方式（任选其一）

| 方式 | 文件 | 说明 |
|---|---|---|
| **exe 双击** | `ClawBoard.exe`（11 MB） | 不用装 Python，双击即用 |
| **脚本运行** | `启动ClawBoard.bat` | 用本机 Python 跑，改一行代码立刻生效，适合继续折腾 |
| **C 原生版** | `ClawBoardC\ClawBoardC.exe`（205 KB） | 核心子集，内存约 15 MB。改代码请用 VS 打开 `ClawBoardC\ClawBoardC.sln` |

- Python 版的数据文件：`ClawBoard数据.json`，位置见下面「数据存在哪」
- C 版的数据文件：`ClawBoardC\ClawBoard数据.json`（格式相同，可以互相拷贝）

## 界面

- 首次启动挂在**屏幕右下角**，拖标题栏可放到任意位置，右下角 `◢` 可自由拉伸
- 标题栏：`—` 折叠成小条 / `📌` 切换置顶 / `✕` 隐藏到托盘（不是退出）
- 双击标题栏 = 折叠/展开
- 系统托盘图标：左键显示/隐藏面板，右键菜单（打开 / 暂停监听 / 设置 / 关于 / 退出）

## 两个主功能

### 剪贴板
自动记录复制的文本（去重叠，默认上限 500 条，可在设置里改成 10~5000）。
截图等图片也会被记录（存到 `images/` 目录），列表里显示「图片 宽×高」，键盘浏览时角落预览大图。
单击条目 = 复制 + 自动粘贴回上一个窗口（模拟 Ctrl+V）。
粘贴时**面板不动**，只有被粘贴的那条会快速闪几下作为反馈；目标窗口是标准编辑控件
（记事本、Word 等）时直接消息投递，浏览器等自绘界面才走抢焦点。
右键：复制 / 粘贴 / 粘贴为纯文本 / 存为常用语 / 拆词 / 文本变换 / 收藏 / **查看详情** / 删除。

### 常用语
顶部是**分组条**（切换、新建、重命名、删除分组）。
底部 `＋` 新增（名称 + 触发词 + 内容）。右键条目：编辑内容 / 命名 / 拆词 / 变换 / 收藏 / 删除。
`拆` 按钮把一段文字按分隔符批量切成多条常用语（自动/换行/逗号/空格/分号/自定义）。

**触发词快速粘贴**：给常用语设一个短触发词（如给地址设 `dz`），在设置里打开「触发词快速粘贴」后，
在任何程序里输入 `dz` 加空格/回车，就会自动替换成完整地址。触发词要求前后都是「词边界」
（前面不是字母/数字），避免误触发；在中文输入法下请切到英文模式输入触发词。

## 搜索语法（F3）

支持**拼音搜索**：直接搜拼音（全拼或首字母）能命中中文内容。
如搜 `zhanghao` 或 `zh` 命中含「账号」的条目——记不清字也能搜到。

| 语法 | 含义 |
|---|---|
| `关键词` | 正文或名称包含，空格分隔多词 = 同时满足 |
| `-关键词` | 排除 |
| `time:2026-10-01` | 指定当天 |
| `time:>1h` / `time:<30m` | 相对时间（s/m/h/d/w） |
| `time:09:00-12:00` | 今天该时段 |
| `time:2026-09-01..2026-09-30` | 日期区间 |
| `app:chrome` | 来源应用，支持中文与模糊（`app:hro` 也行） |
| `type:url` | 类型：text / url / json / multiline |
| `size:>1mb` / `size:<100` | 大小过滤（b/kb/mb/gb） |
| `is:fav` / `is:sens` / `is:est` | 收藏 / 含敏感 / 时间为估算值 |
| `is:pin` | 固定置顶的条目 |
| `tag:email` | 内容标签：邮箱 / 手机号 / 数字 / 日期 / 链接 / 代码 / JSON / 密码 / Token（支持中文，如 `tag:邮箱`） |

内容会自动打标签（识别邮箱、手机号、数字、日期、链接、代码、JSON、密码等），
列表里带 🏷 标记，用 `tag:xxx` 一键筛选。

语法写错不会崩，搜索框变红并在标题栏提示原因。搜索框右键可看最近 10 条历史。

## 文本变换（F4）

27 项：去格式、去空行、去首尾空格、全角半角互转、大小写、小驼峰/大驼峰/下划线/短横线、
JSON 格式化与压缩、Base64 编解码、URL 编解码、MD5/SHA1/SHA256、提取 URL、提取数字、
行排序、行去重、Markdown 转纯文本。

入口：右键「🔧 文本变换」/ 工具条 🔧 / **Ctrl+T**。
底部三个动作：复制到剪贴板、存为新条目（原条目保留）、覆盖原条目（首次复制时间不变）。

## 批量导出（F5）

Ctrl+点选、Shift+连选、Ctrl+A 全选，然后 **Ctrl+E** 或搜索框右键「导出当前结果」。
四种格式：TXT / CSV（带 BOM，Excel 打开中文不乱码）/ JSON（完整字段，可再导入）/ Markdown。
导出到本目录，文件名 `导出_日期时间.后缀`。

## 快捷键

| 键 | 作用 |
|---|---|
| `Ctrl+Shift+V` | 全局唤起/隐藏面板（可在设置里改成 Alt+V 或 Ctrl+Alt+V，被占用时自动降级为轮询检测） |
| `鼠标滚轮` | 列表内容上下滑动，一格滚 3 行；鼠标停在任意一条记录上都能滚 |
| `Ctrl+1`…`Ctrl+9` | 直接粘贴第 1~9 项（按住 Ctrl 时行首会显示序号） |
| `Ctrl+0` | 直接粘贴第 10 项 |
| `↑` `↓` | 上下选择 |
| `Enter` | 粘贴选中项 |
| `Ctrl+Shift+Enter` | 粘贴为纯文本（剥离 HTML 标签与实体） |
| `Delete` | 删除选中项 |
| `Ctrl+F` | 聚焦搜索框 |
| `Ctrl+T` | 文本变换 |
| `Ctrl+E` | 批量导出 |
| `Esc` | 隐藏到托盘 |
| `双击标题栏` | 折叠成只有一条标题栏（再双击展开）。标题栏**整条**都能双击，右边三个按钮除外 |

列表**最右侧**有一条细滑动条：拖滑块可快速定位，点轨道空白处直接跳，鼠标悬停会变亮、拖动变蓝。
内容不满一屏时只留一条淡轨道，不会一直杵着个滑块。

面板**最小尺寸是 280×340**，再往下拖会被挡住 —— 太小的话正文区会被徽章和时间挤没，看着像"里面没有内容"。
窄的时候面板会自己让位：徽章先缩小，再窄就把序号列收起来，优先保证正文能读。

底部工具条同理，窄面板下按优先级把次要按钮**收进 `⋯` 菜单**，而不是把它们压成几像素的细条：

| 面板宽度 | 工具条上剩下什么 | 搜索框实测 |
|---|---|---|
| ≥ 380px | `＋ 拆 删 清 🔧 ? ⚙`（全部） | 144px 起 |
| 356~380px | `拆 删 清 🔧 ? ⚙` + `⋯` | 145px |
| 324~356px | `删 清 🔧 ? ⚙` + `⋯` | 148px |
| < 324px | `删 🔧 ? ⚙` + `⋯` | 108px 起 |

`删 / 🔧 / ? / ⚙` 是高频操作，任何宽度下都直接保留。收进 `⋯` 的**功能一个都没少** ——
点 `⋯` 弹出的菜单里就是「＋ 新增常用语 / 拆 拆词 / 清 清空列表」这几项，
想用随时能点到，不用非把面板拉宽。把面板拉宽会自动全部回到工具条上，顺序和间距不变。

收起状态下这几项还有快捷键：删除选中项 `Delete`，变换 `Ctrl+T`，帮助 `F3`，设置 `Ctrl+,`。

## 内容自适应

列表会按"你复制的到底是什么"来显示，而不是所有条目一个样：

| 类型 | 长什么样 |
|---|---|
| 链接 🔗 | 蓝色强调显示，第二行给出域名 |
| 邮箱 ✉ / 颜色 🎨 / 路径 📁 | 各自的图标 |
| JSON `{ }` / 代码 `</>` | **等宽字体**，一眼看出是代码不是散文 |
| 多行 ¶ | 第二行显示「+N 行」 |
| 普通文本 📝 | 常规字体 |

判定按 `路径 → URL → 邮箱 → 颜色 → JSON → 代码 → 多行 → 文本` 的顺序，命中即停。
两条容易踩的坑已经处理了：**JSON 只认顶层 `{`/`[`**（`123`、`"abc"` 这类标量不算），
**只有 `{}` 不算代码**（散文里太常见，还得有 `;`/`=`/缩进等佐证）。
判定结果在入库时就存好了，列表滚动不会重算。

## 隐私：这些内容不会被记录

1. **带「别记录我」标记的复制**——密码管理器（KeePassXC / 1Password / Bitwarden 等）把密码
   放进剪贴板时，会同时放一个 **Windows 官方标记**告诉所有监听程序「这条别记」。
   ClawBoard 认这个标记，直接跳过。这比靠敏感词正则去猜准得多（可在设置里关掉）。
2. **忽略名单**（设置里可填两类，默认已预置几个密码管理器）
   - 忽略这些程序：`keepass, *bitwarden*, 微信` —— 支持 `*` `?`，不写通配符按「包含」处理
   - 忽略标题匹配的窗口：`密码; Password; ^私密` —— 正则，分号分隔
3. **捕获长度上下限**：短于下限（默认 1）或长于上限（默认不限）的内容不入库，
   用来滤掉单字符噪声和几 MB 的日志正文。
4. **清空历史时保留收藏项**（默认开）：清空按钮只清没收藏的，收藏的留下来。

## 粘贴时前面多了空格？

先说结论：**剪贴板是干净的**，实测写入再读回一个字符都不会多。
问题出在「看起来不一样」——列表里的预览会把首尾空白和换行压平显示，
而粘贴出去的是**原文**。所以从 PDF / 网页 / 代码块复制来的文本（常带前导缩进），
面板里看着没空格，粘出去却带着，就像凭空多了一个。

默认已经在**粘贴时去掉首尾空白**（只去首尾，中间行的缩进保留，代码块不受影响）。
想保留原始缩进的话，在设置里把「粘贴时去掉首尾空白」关掉即可。

## 外观相关的开关

**窗口圆角**（默认开）
调 Windows 11 的 `DWMWA_WINDOW_CORNER_PREFERENCE`，让面板四角变成系统统一的圆角。
Win10 上这个属性不生效，圆角仍是直角 —— 属于正常现象，不是没装对。

**毛玻璃**（默认开）
用 `SetWindowCompositionAttribute` 的 Acrylic 模糊，让面板底下的桌面内容透出一点。
标题栏是自绘的（无边框窗口），所以深色标题栏那套用不上，这里走的是 Acrylic。

**复制提示**（默认开）
新内容入库时，屏幕对应位置弹一个小浮窗显示前几个字，1.8 秒后自动淡出。
关掉的话，设置里还能调停留时长。

**角落完整预览**（默认开）
在选中某条记录后延迟 0.3 秒，于屏幕角落弹一个大窗显示**完整**内容；
代码和 JSON 自动用等宽字体且不换行，超长文本可滚动。面板被折叠时预览窗自动销毁。

这四个开关都是即开即用 —— 改完立刻生效，不用重启。

## 面板尺寸与缩放

面板四边和四个角都能拖动自由拉伸（热区 6 像素，拖角同时改宽高，拖左/上边则同时移动位置）。
也可以在面板里直接改缩放档位：

| 快捷键 | 作用 |
|---|---|
| `Ctrl+=` / `Ctrl++` | 放大一档 |
| `Ctrl+-` | 缩小一档 |
| `Ctrl+0` | 回到 100%（默认被「快速粘贴」占用，若冲突请从设置里改） |

档位为 50% / 75% / 100% / 125% / 150%。缩放会同时作用于布局尺寸与字号，
并且已保存的窗口位置会等比换算，不会缩到屏幕外。

## 设置里的其他开关

**靠边自动隐藏**（默认关）
把面板拖到屏幕**左 / 右 / 上**任意一条边贴住，鼠标移开约 1 秒后面板自动收起，只露出 6 像素；
鼠标再碰到那条边，面板立刻滑出来。不想用就在设置里关掉。

**开机自启**（默认关）
打开开关 → 写入「当前用户」的注册表启动项，不需要管理员权限，下次登录自动启动。
关闭开关 → 这条注册表项被删干净，不留残留。
设置面板每次打开时都从注册表**真实读取**状态，不会出现"显示开着但其实没开"。
不想动注册表的人，可以点设置里的链接打开启动文件夹，自己把快捷方式拖进去。

## 面板点不动 / 找不到了怎么办

按这个顺序排查，基本都能当场解决：

1. **按 `Ctrl+Shift+V`** 唤一次。程序每次唤起都会检查窗口是否完整在屏幕内，
   如果发现它跑到了屏幕外或卡在两个显示器的缝隙上，会自动拉回右下角。
2. **右键托盘图标 → 「⟲ 面板找不到了？重置位置」**，直接把面板归位。
3. **设置 → 点标题栏 ✕ 时 → 改成「直接退出程序」**，这样 ✕ 就是真退出（默认只是隐藏到托盘继续后台监听）。
4. **彻底退出**：托盘右键「退出」，或按 `Ctrl+Q`，或设置面板左下角红色「退出程序」按钮。

为什么以前会点不动：
- 窗口位置记录在配置文件里。如果你上次把它拖到**两个显示器之间**，或者换过显示器/分辨率，
  下次启动它会停在一个"看得见但点不到"的地方。现在程序启动和每次唤起都会自动修正。
- 以前的弹窗用的是**模态锁**，任何一个弹窗没关掉都会让主面板失去响应。现在全部改成"置顶+抢焦点"，
  主面板永远点得动。

## 隐私与安全

- 敏感内容（身份证 / 银行卡 / 手机号 / 邮箱 / Token / 密码串）自动识别：
  列表里默认打码显示，可一键切换原文，也可设置成"检测到就不入库"
- 来源窗口标题默认**不记录**；开启后含"密码/银行卡/登录"的标题一律丢弃
- 日志只写异常，绝不写入剪贴板原文

## 数据存在哪

`ClawBoard数据.json`（UTF-8）。每次迁移前自动备份为 `.bak`，再旧是 `.bak.1` / `.bak.2`，共留 3 份。
想备份就复制这个文件。压测用的 `--bench` 不会写脏数据。

**位置规则（v1.6.1 起）** —— 便携优先，写得进去就跟着 exe 走：

| 情况 | 数据位置 |
|---|---|
| 绿色版 / 放在桌面、U 盘、D 盘 | exe 同目录（**便携**：整个文件夹拷走就能换机） |
| 用安装包装到 `C:\Program Files` | `%APPDATA%\ClawBoard\`（约等于 `C:\Users\你\AppData\Roaming\ClawBoard`） |

为什么要有这条回退：`Program Files` 对普通用户是**只读**的，程序启动时会真的写一个临时文件试探能不能写。
写不进去就换到 `%APPDATA%`，不然会出现这种最糟的情况 —— 界面一切正常，但保存只在 `crash.log`
里留一行「保存失败」，你第二天打开发现历史一条都没记下来。v1.6.0 及更早的安装版就是这个毛病。

崩溃日志 `crash.log` 和数据文件放在一起（超过 512 KB 自动轮转）。

## 卸载与彻底清理

**只想让程序别再跑**：设置面板最下面「彻底清理所有数据」按钮，会关掉开机自启、清空内容、删掉数据文件与备份。

**装完想彻底删掉**：

- **安装版**：开始菜单 →「ClawBoard」→「卸载 ClawBoard」。卸载时会问你一句
  「要一并删除数据吗」——选「否」数据保留在 `%APPDATA%\ClawBoard`，以后重装能接着用；
  选「是」连历史、常用语、设置一起清干净。**开机自启的注册表项无论如何都会删掉**，
  不会留下「开机自动拉起一个已经删掉的程序」这种坑。
- **绿色版**：直接删掉整个文件夹即可（数据就在文件夹里）。
- 收尾检查：托盘图标、右键菜单里的「ClawBoard」项、桌面/开始菜单快捷方式都应一并消失。

## 开机自启（可选，需你手动操作，我不改注册表）

1. 给 `启动ClawBoard.bat` 右键 → 发送到 → 桌面快捷方式
2. `Win+R` 输入 `shell:startup` 回车
3. 把快捷方式拖进去
（设置里的「打开启动文件夹」按钮就是干这个的）

## 已知限制

- 图片只记录、预览，暂不支持「粘贴图片」（图片会存到 `images/` 目录，超量裁剪后旧图文件暂未自动清理）
- 自动粘贴依赖"上一个前台窗口"记录；管理员权限（UAC）窗口会粘贴失败，此时会自动提示"已复制，请手动 Ctrl+V"
- 老数据（无时间戳）的时间是估算值，界面显示带"约"字
