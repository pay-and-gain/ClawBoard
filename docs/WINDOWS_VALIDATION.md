## 已发现并修复

- 文本、文件和图片写回必须在剪贴板事务完成后确认自写序列。Windows 关闭事务时可能合成其他格式，原先记下的序列会过期，导致自身内容被再次采集。确认时还必须区分期间发生的外部复制。
- 普通粘贴与触发词替换共用有界串行队列。触发词先准备剪贴板，再核对原窗口、焦点控件、取消状态和剪贴板序列；剪贴板准备失败或目标变化时不退格。
- `SendInput` 检查完整注入数量；退格包含按下和释放事件，删除与粘贴在同一批次发送。部分注入失败会释放可能残留的按键并反馈失败。
- 托盘 `NOTIFYICONDATA` 的 `uTimeout/uVersion` 改为 Win32 联合体布局；消息窗口使用独立窗口类，并在所属线程清理热键、监听器、图标和窗口类，支持同进程重复创建。
- 多屏坐标用半开区间判定屏幕归属，避免左侧或上方副屏边界为 0 时被误认成主屏。
- 跨屏稳定落屏并松开鼠标后，主面板同步更新字体、布局、窗口尺寸和最小尺寸；用户缩放档位保持。隐藏期间不唤醒窗口，重新显示后适配；搜索、输入选区、列表选择/多选与滚动位置保留，等待异步结果的恢复快照绑定当前视图。
- `_t42` 改为验证当前异步补记服务的实际完成结果；`_t43` 修正临时路径、文件原本不存在时的 hash 验证和失败退出码。
- 点击、滚轮、继续键入和快捷键会取消排队替换；Enter/Tab 保留目标程序原行为并取消展开，避免先提交表单再删除其它正文。键盘/鼠标钩子共用生命周期，任一安装失败即停用触发监听。
- 中文输入法候选提交后不能按原始拼音长度退格。每次输入查询焦点线程 HKL，仅允许完整标识 `0x04090409`，查询失败、CJK、US International/Dvorak 等均跳过。布局改变会清空缓冲并取消旧请求；排队、准备剪贴板前后和真正发送退格批次前再次核对。原生 Edit 中实际中文布局、HTTP 测试页真实候选提交和独立 US 布局的人工展开均已通过。
