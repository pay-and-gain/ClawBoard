# 误删回收站

入口：**设置 → 数据 → 回收站**。此功能属于本地待发布改动，公开 v2.7.0 安装包尚未包含。

## 删除与保留

手动删除历史、常用语、清空当前列表或删除常用语分组时，内容先移入回收站。清空历史仍遵守“保留收藏项”。原分组被删除后，恢复其内容时会重新建立分组，不会仅凭同名把内容并入另一个分组。

内容最多保留 **30 天**；到期后在下一次保存或打开回收站维护时清理。最多容纳 **5000 条**，满额会拒绝新的移入并保留源内容，不会提前清除尚未到期的记录。

达到“历史最大条数”后的自动裁剪仍沿用原有行为，**不进入回收站**。回收站内的图片保留到对应记录永久移除并成功保存之后；保存失败时不会先删除图片。

## 预览与恢复

1. 打开回收站，选择一条或多条记录；需要时点击“刷新”。
2. 核对删除时间、原位置及预览。敏感内容沿用原有打码设置，长内容只截断显示。
3. 点击“恢复所选”。恢复保留完整原文、时间、来源和未知扩展字段；不会自动粘贴到其他程序。

双击或 Enter 只进入预览。图片恢复后可在主面板查看。恢复常用语时，若触发词已被当前常用语占用，会拒绝该批恢复并保留回收站内容，避免覆盖或偷偷启用重复触发词。

## 永久删除与备份

“永久删除所选”和“清空回收站”都需要再次确认。永久删除不能从当前回收站撤销；另存的完整备份包仍然保留原来的内容。

完整备份会包含回收站及其图片，预览显示回收站条数。普通 JSON 导出继续只导出当前记录，不是回收站备份。回收站与完整备份都未加密。

设置中的“清理当前资料库”是明确的彻底清理，包含回收站，不会再次移入回收站。执行前先保留需要的完整备份。

共享 JSON 的 schema 仍为 3，回收站使用可选的 `trash` 扩展；旧程序不会显示这项功能。不要依赖旧版本管理或恢复回收站内容。
