# 完整备份与恢复

入口：**设置 → 数据 → 完整备份与恢复**。此入口适用于 v3.0.0；普通 JSON 导出仍保留原有格式。

## 创建备份

1. 点击“创建完整备份”，选择一个新的 ZIP 文件名。
2. 程序先确认当前资料已保存，再在后台创建备份。
3. 等待界面显示完成后，保留该 ZIP；需要时可以另存到自己的备份设备。

备份包含历史记录、常用语、回收站、设置、记录所引用的图片，以及版本和文件校验清单。原 JSON 字节和未知扩展字段保留，共享数据格式不变。

文件条目保存的是原文件路径，**不会把路径指向的文档、视频或整个文件夹复制进备份**。Windows 的安装登记、开机启动登记也不在包内。备份没有加密，敏感记录在包内仍是明文。

## 恢复备份

1. 点击“选择备份并预览”，选择 ClawBoard 创建的完整备份 ZIP。
2. 核对创建时间、程序版本、历史条数、常用语条数、回收站条数、图片数和体积。
3. 确认恢复。恢复会替换当前资料库及设置，程序需要重新启动。

程序正常保存退出后，辅助进程才开始操作资料库。恢复之前，会在数据文件同层创建独立的 `ClawBoard恢复前_日期时间_标识.zip`，保留恢复前的 JSON 和图片。不会自动删除这份备份。

如果退出前保存失败，本次恢复会取消，原程序保持打开。备份文件从预览后发生变化时，也会取消恢复。

恢复中断后，下次正常启动会先处理未完成事务，再打开资料库。无法确认安全恢复时，程序停止载入，保留原件、恢复前备份和事务记录；请不要只删除其中某一个文件后重试。

## 与 JSON 导出的区别

| 文件 | 内容 | 可用于完整恢复 |
|---|---|---|
| 完整备份 ZIP | 历史、常用语、回收站、设置、引用图片、校验清单 | 可以，先预览再确认 |
| 普通 JSON 导出 | 所选或全部记录字段，不含设置和图片本体 | 不可以；当前没有内容合并导入功能 |

如果原 JSON 已损坏，恢复前安全快照仍会原样保存损坏文件及现存图片，便于取回原件；这类快照不能冒充有效资料库再次自动恢复。

## 大小和保护范围

单份 JSON 上限 64 MiB，单张图片上限 64 MiB，资料总大小上限 512 MiB，ZIP 成员数量上限 10002。超过上限会报告失败，不会截断记录或删除原资料。

程序会核对成员路径、完整性和图片引用，拒绝损坏、缺图、越界路径或不兼容的包。恢复仅处理当前资料文件和被引用的图片，不删除数据目录中的无关文件，也不打开文件条目指向的外部文件。

“清理当前资料库”会清理当前 JSON、图片和旧迁移备份；你另存的完整备份 ZIP 会保留。要移除这些 ZIP，请先确认已经不再需要。
