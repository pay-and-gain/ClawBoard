## 接续入口

1. 先读本文件和 [维护交接摘要](../../maintenance/HANDOFF.md)，再看 [产品决策](DECISIONS.md)；只按需读相关模块。
2. 核对分支、工作树、当前构建及本批实际测试结果，不重复执行已完成的部署。
3. App 测试先指向临时数据和日志目录，再在构造前设置 `NO_SAVE`。日常实例运行时不跑剪贴板或 App 专项，正常退出后再持有产品测试租约。
4. 公开仓库保留源码、说明、合成截图和校验索引；安装包及便携包使用 Release 附件。真实资料、研究原稿、原始日志和完整对话不作为公开归档。
5. 正式更新程序前完整备份；回退只替换 exe，保留后来新增历史。产品版本号只在明确发版批次统一修改。
