# 升级进展与接续

更新日期：2026-10-28。**v4 正在准备，尚未完成本轮验收或发布。** 已公开版本为 v3.0.0；后续内容合并导入已完成本机验证和本地增强构建。

- 保持 Python 标准库、tkinter、ctypes/Win32；零第三方运行依赖，Python/C 共用 JSON schema 3。
- 已交付纸感爪印亮暗界面、紧凑面板、可视筛选、设置五分区和按需只读工作台。
- 已交付完整 ZIP 备份与整库恢复、误删回收站及内容合并导入。导入先预览，保留当前内容和设置；重复跳过，同名分组另建，冲突触发词停用。
- 已有功能和边界见 [新手指南](../../getting-started.md)、[备份与恢复](../../backup-and-restore.md)、[回收站](../../recycle-bin.md)及[合并导入](../../merge-import.md)。

## 本轮正在进行

1. 复核所有子窗口，将保存、确认、取消及删除等关键操作置于顶部可见区域，检查最小尺寸、长正文和跨屏缩放。
2. 精简入口和重复说明，保留快速面板效率；入口分层细节以本轮确认后的产品决策为准。
3. 更新中英文首页、指南、真实 Tk 合成截图和发布说明，核对版本号与下载文件名。
4. 脱敏公开源码和维护文档，准备源码、安装包、便携包、校验及可回溯发布归档。

这些是正在进行的范围，不代表 v4 已通过验收。保存搜索、项目口袋、处理配方、OCR、富文本、加密和云服务均不因本轮界面整理自动纳入产品。

## 接续入口

1. 先读本文件和 [维护交接摘要](../../maintenance/HANDOFF.md)，再看 [产品决策](DECISIONS.md)；只按需读相关模块。
2. 核对分支、工作树、当前构建及本批实际测试结果，不重复执行已完成的部署。
3. App 测试先指向临时数据和日志目录，再在构造前设置 `NO_SAVE`。日常实例运行时不跑剪贴板或 App 专项，正常退出后再持有产品测试租约。
4. 公开仓库保留源码、说明、合成截图和校验索引；安装包及便携包使用 Release 附件。真实资料、研究原稿、原始日志和完整对话不作为公开归档。
5. 正式更新程序前完整备份；回退只替换 exe，保留后来新增历史。产品版本号只在明确发版批次统一修改。

[PLAN.md](PLAN.md) 和浏览器设计样机是历史候选对照，不是当前已实现功能清单；以本文件、产品说明与发布说明为准。
