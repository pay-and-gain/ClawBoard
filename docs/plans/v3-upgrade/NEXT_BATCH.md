## 1. 内容合并导入（推荐）

设想入口：设置 → 数据 → 导入资料。先支持 ClawBoard 自身导出或备份，跨软件格式另行确定。

用户选文件后看到资料预览：可加入的记录、疑似重复、分组及触发词冲突，再勾选本次要加入的内容。确认前生成安全备份，原有资料继续保留。

master 已选择安全规则：同类相同内容跳过；同名常用语分组另建带“导入”后缀的分组；冲突触发词停用并提示。现有设置与回收站不导入覆盖。历史容量不足时拒绝本次导入，用户可减少选择或主动修改容量，不自动裁剪或改设置。JSON缺少图片正文的条目标记不可导入，不跟随旁边目录读取图片；完整备份ZIP可包含图片。确认后正常保存退出，由独立辅助进程在互斥保护下读取最终库再合并，完成后重启，保留预览期间后来新增的历史。

例如当前已有500条历史，从旧备份挑出50条需要的资料加入；不需要用旧备份整库覆盖当前资料。相同内容、同名分组、触发词冲突的具体规则应在选定本方案后确定。

主要代价：导入格式、重复判定、图片与失败回退需要较多验证。

## 2. 保存搜索

设想入口：工作台中的“保存当前筛选”和“我的搜索”。例如将“最近七天＋收藏＋链接”命名为“本周常用链接”。下次启动直接点名称即可重新筛选。

建议保存筛选条件，结果随新资料与日期变化。它不另外复制资料；原记录删除后不会继续显示在结果中。

主要代价：收益集中于反复搜索的人；需要处理改名、删除和不再有效的筛选条件。

## 3. 项目口袋 / 续上昨天

设想入口：工作台 → 项目。用户建立一个项目，主动加入片段和图片，写备注和“下一步”。再次打开程序能看到上次材料与下一步。

例如“装修计划”下集中收纳尺寸、报价和图片，下一步写“比较两个商家的安装费”。文本和图片材料需有独立持久副本，普通历史淘汰不会使它们消失。外部文件正文是否复制、容量上限与导出方式须专项确定。

主要代价：范围最大，涉及长期材料管理、备份和图片清理；小面板保持紧凑，管理入口放在按需工作台。
