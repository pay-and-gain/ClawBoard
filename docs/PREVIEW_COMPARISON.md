# 重构预览版前后对照

本次交付仍使用 **2.6.1** 版本号，数据格式保持 **schema 3**，保留 tkinter 和零运行时第三方依赖。它来自 `refactor/services-and-responsiveness` 分支，用于审阅和评估，**不是新的正式 Release**。

## 行为与工程改进

| 项目 | 重构前的风险或组织方式 | 本次预览版 |
|---|---|---|
| 输入法与触发词 | 原始键码的字母数可能与输入法提交的文字数不同，退格替换可能误删正文 | 仅对独立标准 US 布局启用展开；中文输入法、微软拼音“英”模式及未知布局暂停展开；排队和注入前复核布局与目标 |
| 管理员窗口 | 系统接受发键事件，不代表更高权限的输入框实际收到内容 | 发键前检查双方权限；更高或未知权限停止自动发键，保留已复制内容并提示手动 Ctrl+V |
| 混合 DPI 主面板 | 跨屏后字体、行高和窗口尺寸可能不同步 | 稳定落屏后同步字体、布局、窗口和最小尺寸，保留用户缩放档位、搜索与列表状态；125%/150% 双屏往返已验证 |
| 粘贴与剪贴板 | 触发替换与普通粘贴可能争用剪贴板；自写序列的确认时机可能遗漏格式合成或外部复制 | 共用有界串行队列；先准备内容，再检查焦点、取消状态和序列；用自写标记核实事务关闭后的序列 |
| 托盘恢复 | 消息专用窗口不能接收 Explorer 重建托盘的广播 | 改用隐藏顶层窗口接收恢复消息，复用图标资源；首次添加失败后也保留重试意图，显式停用或退出后不恢复 |
| 服务与维护 | 数据、查询、保存及系统操作更多地集中在共享窗口逻辑中 | 拆出模型、搜索、保存、后台任务和 Windows 适配器；工作线程通过队列交回结果，兼容旧入口和数据字段 |

安装脚本修正了卸载确认的默认按钮和静默卸载行为，默认保留数据；只删除属于本安装的自启动项，保留其它目录便携版的同名设置；启用 `/NOICONS` 支持。静态合同、编译及本机独立目录的静默安装/启动/保留数据卸载已通过。

## 体积与性能证据

| 对照项 | 既有便携构建 | 本次便携构建 |
|---|---:|---:|
| exe 文件大小 | 12,540,974 B | 14,171,899 B |

本次 exe 增加 **1,630,925 B，约 13.0%**。服务与适配模块增多，不能宣称本轮减少了发布体积。

云端对同一组合成输入进行的查询、图像编解码与可见行投影对照，见[项目审阅与性能记录](PROJECT_REVIEW.md)。这些结果用于定位 CPU 工作的改善；本轮没有旧、新 Windows GUI 的统一延迟、帧率、启动或内存对照，不能据此承诺实际界面速度提升。exe 启动烟测也不等同于性能测试。

## 已验证与尚未完成

本轮验证包含真实剪贴板文本/文件/图片闭环、浏览器粘贴、中文候选提交保护、独立 US 触发词、管理员目标的安全降级与手动粘贴，以及混合 DPI 主面板。托盘恢复已覆盖消息接收和本程序自身图标移除后的恢复路径。

**真实 Explorer 重启、物理托盘点击、交互式安装向导及长期运行仍未验收。** 安装测试在本机独立目录进行，不是虚拟机测试；合成数据的保存/重载由存储层验证，程序启动使用 NO_SAVE，未验证 GUI 保存后重启的完整流程。独立弹窗也不能直接套用主面板的 DPI 结论。焦点检查与系统执行之间仍有短竞态，自动输入无法保证任意目标应用都接受内容。

完整场景和复现入口见 [Windows 验证记录](WINDOWS_VALIDATION.md)，模块边界见[当前架构说明](REFACTOR.md)。使用预览版前应备份已有数据并保留旧程序；本次交付不会自动迁移或替换现有版本。
