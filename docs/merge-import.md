# 内容合并导入

从“设置 → 数据 → 合并导入资料…”打开。此功能只向当前库加入选中的历史和常用语；当前设置、回收站及已有内容保留。

## 使用步骤

1. 选择 ClawBoard JSON 导出或完整 ZIP 备份包，点击“检查并预览”。
2. 查看条目、重复说明、触发词冲突和完整内容预览。默认选中可导入项；按住 Ctrl 多选，Shift 连续选择。
3. 可“取消全选”后只选需要的内容。缺少图片正文的条目不可导入。
4. 点击“导入所选…”，核对数量后确认。程序正常保存并短暂退出，辅助进程在独占保护下读取最终资料、先完整备份，再合并并重新启动。
5. 重新打开后显示导入结果、跳过重复和停用触发词数量，以及导入前备份位置。

预览期间新复制的内容会保留；执行时若容量或源文件变化导致不能安全加入，本次导入取消，可重新预览。

## 安全规则

- 同类记录的相同内容跳过；历史与常用语分别判重。图片比较已校验的正文摘要，不能只凭文件名判重。
- 常用语作为独立分组加入；名称冲突时加“（导入）”后缀，再冲突则编号。已有分组不合并覆盖。
- 已占用的触发词先停用，并在预览和结果中提示，可自行重新设置。
- 新条目使用新标识，图片使用新名称，避免覆盖当前历史、回收站及图片。
- 导入遵循当前隐私遮罩；不会沿用来源条目的临时明文显示标记。遮罩影响显示，数据文件和备份仍为明文。
- 历史容量不足时取消本次导入，不自动删除记录或提高容量。可减少所选条目，或自行到设置中调整容量。
- 导入前生成与完整恢复同级的安全备份；写入失败或中断使用持久事务回退。请保留数据目录中的安全备份和未完成事务记录。

## 支持与边界

支持本程序的全部 JSON 导出、选中记录 JSON 导出、共享库 JSON 和完整 ZIP 备份。首批不包含其它软件的格式转换、CSV/TXT导入，也不导入来源的设置或回收站。

JSON 只有图片引用，不能携带图片正文；缺图条目会标记不可导入。程序不自动读取所选 JSON 旁边的图片文件。完整 ZIP 备份可携带并校验图片。

文件类型记录只保留原路径，不复制外部文件正文；换电脑后原路径可能失效。完整备份包须通过现有大小、成员名、版本和摘要校验，单次最多处理10000条候选记录。

合并导入与“完整恢复”分开：完整恢复用于回到整份库及设置；合并导入用于挑选内容加入当前库。两个入口均保留预览与操作前备份。
