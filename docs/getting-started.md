## 30 秒上手（TL;DR）

如果只想记住三件事，就记住这三步：

1. **启动** —— 双击 `ClawBoard.exe`。它会安静地挂在屏幕右下角，并在系统托盘留一个图标。
2. **唤起** —— 在任何界面按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>，弹出剪贴板面板。
3. **粘贴** —— 用 <kbd>↑</kbd> <kbd>↓</kbd> 选中条目，按 <kbd>Enter</kbd>，内容自动粘贴回你刚才的窗口。

就这么多。剩下的一切都是锦上添花。

## 安装

三种方式任选其一。**没有安装包依赖，没有 pip，不联网。**

<details open>
<summary><b>方式一 · 安装包（推荐）</b></summary>

1. 到 [Releases 页面](../../releases/latest) 下载 `ClawBoard-2.2.4-setup.exe`。
2. 双击，一路「下一步」。
3. 安装完成会自动创建开始菜单和桌面快捷方式，并附带卸载项。

> [!NOTE]
> 用安装包装到 `C:\Program Files` 时，数据会存到 `%APPDATA%\ClawBoard\`（因为 Program Files 对普通用户只读）。详见 [FAQ：数据存在哪？](#常见问题-faq)。

</details>

<details>
<summary><b>方式二 · 绿色版（解压即用）</b></summary>

1. 下载 `ClawBoard-2.2.4-portable.zip`。
2. 解压到任意目录（U 盘、桌面、D 盘都行）。
3. 双击 `ClawBoard.exe`。

> [!TIP]
> 绿色版不写注册表、不留残留。数据就落在 exe 旁边，**整个文件夹拷走就能换电脑**。

</details>

<details>
<summary><b>方式三 · 从源码运行</b></summary>

```bash
git clone https://github.com/pay-and-gain/ClawBoard.git
cd ClawBoard
python ClawBoard.py     # 需要 Python 3 + tkinter（Windows 自带）
```

零 pip 依赖 —— 只用 Python 标准库（tkinter + ctypes）。

想要一个独立 exe：

```bash
pip install pyinstaller
pyinstaller packaging/ClawBoard.spec --noconfirm
# 产物在 dist/ClawBoard.exe，数据文件落在 exe 旁边
```

</details>

> [!IMPORTANT]
> **系统要求**：Windows 10 / 11。圆角窗口、毛玻璃等视觉效果在 Win10 上会退化为直角/无模糊，属于正常现象，不影响功能。

## 5 分钟教程：找回你刚复制的内容

### 第一个任务：把你刚复制、又弄丢的那段内容找回来

这是一个最短的操作闭环，跟着做一遍就懂了。

**第 1 步 · 让 ClawBoard 跑起来**

双击 `ClawBoard.exe`（或安装后的快捷方式）。屏幕右下角出现一个窄窄的面板，托盘区多一个小图标 —— 说明它已经在后台记录剪贴板了。

**第 2 步 · 复制点东西**

随便打开一个网页或文档，选中一段文字，按 <kbd>Ctrl</kbd>+<kbd>C</kbd>。面板顶部会浮出一个小提示（默认开），告诉你「已记录」，说明捕获成功。

**第 3 步 · 唤起面板**

切到任意窗口，按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>。面板弹出，你刚复制的内容就在列表**最上面**。

**第 4 步 · 选中并粘贴**

- 用 <kbd>↑</kbd> <kbd>↓</kbd> 把光标移到那一条，按 <kbd>Enter</kbd>；
- 或者**直接用鼠标单击**那一行。

内容会**自动粘贴回你刚才的窗口**（ClawBoard 模拟了一次 <kbd>Ctrl</kbd>+<kbd>V</kbd>）。面板本身不会动，只有被粘贴的那条会快速闪几下作为反馈。

✅ **搞定。** 你已经掌握了 ClawBoard 的核心闭环：**复制 → 唤起 → 粘贴**。

### 再试试（2~3 个小任务，覆盖核心功能）

练完上面，再挑几个试试，基本就摸透了：

- **任务 A · 搜索** —— 按 <kbd>Ctrl</kbd>+<kbd>F</kbd> 聚焦搜索框，输入关键词，列表实时过滤。试试中文、英文，甚至拼音：输入 `zhanghao` 或 `zh`，也能命中含「账号」的条目。
- **任务 B · 收藏** —— 把鼠标移到一条常用内容上，右键 → 收藏。收藏项在「清空历史」时会被保留。
- **任务 C · 图片** —— 用系统截图工具（<kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>）截一张图，面板里会出现「图片 宽×高」；选中它，角落会弹出大图预览。

> [!TIP]
> 想更快？复制后直接按 <kbd>Ctrl</kbd>+<kbd>1</kbd>…<kbd>Ctrl</kbd>+<kbd>9</kbd> 就能粘贴最近的第 1~9 条，连面板都不用选。

## 核心功能逐个上手

### 📋 剪贴板历史

**是什么**：自动记录你复制过的每一条文本，重复复制只累计次数、不重复建条目。

**怎么用**：什么也不用做，复制就是了。悬停条目看复制时间，右键看详情（三个时间 + 来源应用 + 大小）。

**小技巧**：
- 上限可配（默认 500 条，设置里可改 10~5000）。
- 「清空历史」默认**保留收藏项**，不会把你精心标星的内容一起清掉。
- 右键 → **粘贴为纯文本** 可以剥掉 HTML 标签和实体，粘到记事本里不会带样式。

### 🔍 高级搜索

**是什么**：一套类命令行的搜索语法，能按来源、时间、类型、大小、状态、标签精确筛选。

**怎么用**：<kbd>Ctrl</kbd>+<kbd>F</kbd> 聚焦搜索框，直接输入：

| 语法 | 含义 |
|---|---|
| `关键词` | 正文或名称包含；空格分隔多词 = 同时满足（AND） |
| `-关键词` | 排除 |
| `app:chrome` | 来源应用，支持中文与模糊匹配（`app:hro` 也行） |
| `time:>1h` / `time:<30m` | 相对时间（s/m/h/d/w） |
| `time:09:00-12:00` | 今天该时段 |
| `time:2026-09-01..2026-09-30` | 日期区间 |
| `type:url` | 类型：text / url / json / multiline |
| `size:>1mb` / `size:<100` | 大小过滤（b/kb/mb/gb） |
| `is:fav` / `is:sens` / `is:est` / `is:pin` | 收藏 / 含敏感 / 时间为估算值 / 固定置顶 |
| `tag:email` / `tag:邮箱` | 内容标签筛选 |

**小技巧**：语法写错不会崩，搜索框会变红并在标题栏提示原因；搜索框右键可看最近 10 条搜索历史。

### 🔤 拼音搜索

**是什么**：记不清汉字也能搜到内容。

**怎么用**：直接输入拼音（全拼或首字母）。搜 `zhanghao` 或 `zh` 就能命中含「账号」的条目。

**小技巧**：多音字按**词组**纠正 —— 「重庆」正确地拼成 `chongqing`、「银行」拼成 `yinhang`、「长城」→ `changcheng`、「音乐」→ `yinyue`，不会因为单字读音歧义而搜不到。

### 🏷 内容标签

**是什么**：复制内容会被自动识别并打上标签，列表里带 🏷 标记。

**怎么用**：用 `tag:xxx` 一键筛选。识别类型共 11 类：邮箱 / 手机号 / 身份证 / 银行卡 / 数字 / 日期 / 链接 / 代码 / JSON / 密码 / Token。支持中文别名（`tag:邮箱`）。

**小技巧**：JSON 优先于代码 —— `{"a":1}` 会被识别为 JSON 而不是代码。

### 🖼 图片剪贴板

**是什么**：截图、复制图片也会被记录、预览，**并且能粘回去**。

**怎么用**：
- 用截图工具截图后，面板里出现「图片 宽×高」条目。
- 键盘浏览（<kbd>↑</kbd> <kbd>↓</kbd>）时，屏幕角落弹出大图预览。
- 点图片条目 → 粘回微信 / QQ / 文档。

**小技巧**：图片文件存于数据目录下的 `images/`。删除、清空、超量裁剪图片条目时会同步清理对应的 PNG，不积累垃圾。

> [!NOTE]
> 从 v2.2.0 起，图片功能与文本完全对称（记录 / 预览 / 粘贴）。v2.2.2 修复了 24 位截图与自顶向下 DIB 的记录，v2.2.3 修复了文件复制（`CF_HDROP`）。

### 💬 常用语 & 触发词

**是什么**：把你经常要打的整段内容（地址、回复模板、签名档）存为「常用语」，随取随用。

**怎么用**：
- **常用语页**：分组管理（切换 / 新建 / 重命名 / 删除分组）；底部 `＋` 新增（名称 + 触发词 + 内容）。
- **拆词**：`拆` 按钮把一段文字按分隔符（自动 / 换行 / 逗号 / 空格 / 分号 / 自定义）批量切成多条常用语。

**触发词快速粘贴**（重点功能）：
1. 给常用语设一个短触发词，比如给地址设 `dz`。
2. 设置里打开「触发词快速粘贴」。
3. 之后在**任何程序**里输入 `dz` 再按空格/回车，就会自动替换成完整地址。

**小技巧**：触发词要求**词边界**（前面不能是字母/数字），避免误触发；在中文输入法下请先切到**英文模式**再输入触发词。

### 📟 命令面板

**是什么**：一个模糊搜索的命令入口，不用记菜单在哪。

**怎么用**：按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> 呼出，输入命令名，模糊过滤后回车执行。

**小技巧**：重复按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> 只会聚焦已有面板，不会叠加打开多个。

### 🔧 文本变换（27 项）

**是什么**：对选中条目做即时文本处理。

**怎么用**：<kbd>Ctrl</kbd>+<kbd>T</kbd> 打开（或右键「🔧 文本变换」）。27 项包括：去格式、去空行、去首尾空格、全角/半角互转、大小写、小驼峰/大驼峰/下划线/短横线、JSON 格式化与压缩、Base64 编解码、URL 编解码、MD5/SHA1/SHA256、提取 URL、提取数字、行排序、行去重、Markdown 转纯文本等。

**小技巧**：变换后底部有三个动作 —— 复制到剪贴板 / 存为新条目（保留原条目）/ 覆盖原条目（首次复制时间不变）。

### 📤 批量导出

**是什么**：把筛选结果导出成文件。

**怎么用**：Ctrl+点选、Shift+连选、<kbd>Ctrl</kbd>+<kbd>A</kbd> 全选，然后按 <kbd>Ctrl</kbd>+<kbd>E</kbd>（或搜索框右键「导出当前结果」）。

**小技巧**：四种格式 —— **TXT / CSV（带 BOM，Excel 打开中文不乱码）/ JSON（完整字段，可再导入）/ Markdown**。导出到本目录，文件名 `导出_日期时间.后缀`。

## 隐私与安全

> [!WARNING]
> **ClawBoard 会主动跳过敏感内容。**
> - 遵守 Windows 官方的「别记录我」标记 —— 密码管理器（KeePassXC / 1Password / Bitwarden 等）把密码放进剪贴板时会带这个标记，ClawBoard 认它，直接跳过（比靠敏感词正则去猜准得多）。
> - **程序 / 标题忽略名单**：默认已预置几个密码管理器；也可自定义「忽略这些程序」「忽略标题匹配的窗口」。
> - **敏感内容识别**：身份证 / 银行卡 / 手机号 / 邮箱 / Token / 密码串会被自动识别，列表中默认**打码显示**，可一键切换原文，也可设成「检测到就不入库」。
> - 来源窗口标题默认**不记录**；日志只写异常，**绝不写入剪贴板原文**。

> [!TIP]
> **使用建议**：
> - 如果在意隐私，建议保持「遵守 Windows 别记录我标记」和「敏感内容打码」为开启状态。
> - 把密码管理器的进程名加进忽略名单。
> - 定期备份数据文件（见下方 FAQ），并对备份文件本身加密或放在安全位置。

## 常见问题 FAQ

**Q1：按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> 没反应？热键被占用了怎么办？**
可能是被其他程序抢占了。到 **设置** 里把唤起热键改成 <kbd>Alt</kbd>+<kbd>V</kbd> 或 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd>。若热键注册失败，程序会**自动降级为轮询检测**（退回监听默认的 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>），依然能唤起，只是响应稍慢。

**Q2：数据存在哪？**
一个 UTF-8 的 `ClawBoard数据.json` 文件。位置规则是**便携优先**：
- 绿色版 / 放在桌面 / U 盘 / D 盘 → 就在 exe 同目录。
- 用安装包装到 `C:\Program Files` → 落到 `%APPDATA%\ClawBoard\`（因为 Program Files 对普通用户只读）。

图片存在数据目录下的 `images/`；崩溃日志 `crash.log` 与数据文件放在一起。

**Q3：怎么备份？**
直接复制 `ClawBoard数据.json` 即可。程序在每次数据迁移前会自动备份为 `.bak`，再旧是 `.bak.1` / `.bak.2`，共留 3 份。要换机，绿色版整个文件夹拷走就行。

**Q4：我在资源管理器里复制了一张图片「文件」，为什么记录的是路径而不是图片？**
这是**预期行为**。在资源管理器里对 jpg/png 按 <kbd>Ctrl</kbd>+<kbd>C</kbd>，复制的其实是**文件路径**（Windows 剪贴板格式为 `CF_HDROP`），而不是图像像素数据 —— 所以 ClawBoard 记录的是路径文本（v2.2.3 起支持，多文件用换行连接）。
想记录**图像本身**，请用截图工具，或把图片**粘贴进支持图像的程序**后再复制图像内容。

**Q5：开机自启怎么设？**
**设置** → 打开「开机自启」开关。它会写入当前用户的注册表启动项（不需要管理员权限），关闭时该项会被删干净。不想动注册表的话，可点设置里的「打开启动文件夹」按钮，自己把快捷方式拖进 `shell:startup` 文件夹。

**Q6：点粘贴没粘到目标窗口？**
自动粘贴依赖「上一个前台窗口」记录。**管理员权限（UAC）的窗口会粘贴失败** —— 这时程序会自动提示「已复制，请手动 <kbd>Ctrl</kbd>+<kbd>V</kbd>」，内容已在剪贴板里，手动粘贴即可。

**Q7：面板点不动 / 找不到了怎么办？**
按顺序排查：① 再按一次 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>（程序每次唤起都会自动把跑到屏幕外的窗口拉回右下角）；② 右键托盘图标 → 「⟲ 面板找不到了？重置位置」；③ 检查窗口是否被拖到了两个显示器之间的缝隙。

**Q8：粘贴出来怎么前面多了空格？**
剪贴板本身是干净的。列表里的预览会把首尾空白和换行压平显示，而粘贴出去的是**原文** —— 从 PDF/网页/代码块复制的文本常带前导缩进，看着像凭空多了空格。默认已在**粘贴时去掉首尾空白**（中间行的缩进保留，代码块不受影响）；想保留原始缩进可在设置里关掉这个选项。
