# ClawBoard 新手指南

**简体中文** | [English](getting-started.en.md) · [返回首页](../README.md)

ClawBoard 用来找回复制过的内容，并把常用文字放在随时可用的面板里。先用一段无敏感信息的测试文字，走完一次“复制 → 找到 → 粘贴”。

> 本指南适用于 **v2.7.0**。旧 v2.6.1 不包含本轮输入法和权限保护，仍使用旧版时请关闭触发词；升级前备份数据文件和图片目录。

## 1. 选择运行方式

**直接使用正式版**：到 [v2.7.0 发布页](https://github.com/pay-and-gain/ClawBoard/releases/tag/v2.7.0)，选择便携包或安装包。两种打包形式都不需要安装 Python。

- [ClawBoard-2.7.0-portable.zip](https://github.com/pay-and-gain/ClawBoard/releases/download/v2.7.0/ClawBoard-2.7.0-portable.zip)：完整解压到一个可写文件夹，再双击 `ClawBoard.exe`。以后保持 exe 与数据文件同层。
- [ClawBoard-2.7.0-setup.exe](https://github.com/pay-and-gain/ClawBoard/releases/download/v2.7.0/ClawBoard-2.7.0-setup.exe)：按向导选择安装位置；桌面快捷方式是可选项。

**从源码运行**：准备 Windows 10/11、Git、Python 3.10+，安装 Python 时包含 Tcl/Tk，然后运行：

```powershell
git clone https://github.com/pay-and-gain/ClawBoard.git
cd ClawBoard
python ClawBoard.py
```

运行只需要 Python 标准库，没有 pip 依赖。本轮源码变更见 [PR #1](https://github.com/pay-and-gain/ClawBoard/pull/1)。源码运行的数据默认写在该源码目录，开发测试使用独立临时数据。

## 2. 第一次复制和粘贴

1. 启动程序。在记事本或浏览器输入框写下 `ClawBoard 测试 ABC`，选中并按 **Ctrl+C**。
2. 点击准备接收内容的输入位置，按 **Ctrl+Shift+V**。面板应出现，刚复制的条目位于列表前部。
3. 用 **↑ / ↓** 选中该条目并按 **Enter**，或者单击条目。默认开启自动粘贴。
4. 检查目标输入框的实际内容。若提示“已复制，请手动 Ctrl+V”，回到目标框手动粘贴；若提示剪贴板写入失败，先重试复制。

## 3. 找到历史内容

按 **Ctrl+F** 聚焦搜索，输入关键词。多个词需要同时匹配；`-关键词` 可以排除内容。

| 示例 | 用途 |
|---|---|
| `项目 地址` | 同时包含两个词 |
| `app:chrome` | 按来源应用筛选 |
| `type:url` | 找链接 |
| `is:fav` | 只看收藏 |
| `tag:email` | 找带邮箱标签的内容 |
| `time:09:00-12:00` | 找今天某个时段的记录 |

中文也可以用全拼或首字母搜索，例如 `zhanghao` 或 `zh` 查找“账号”；不会展开所有多音字读法。右键条目可收藏、查看详情或删除。

截图工具复制的图像会保存为图片条目；在资源管理器复制 jpg/png **文件**时，记录的是文件路径。文件路径记录不等于文件备份，原文件移动或删除后仍需自行处理。

程序启动时可以补记当时可读的当前剪贴板，但无法恢复关闭期间全部复制历史；快速连续复制也不保证捕获每一个中间状态。

## 4. 保存常用语

切换到“常用语”页，选择分组，再点底部 **＋**，填写名称和正文。触发词可以留空；以后点击条目即可复制或粘贴。历史条目也能通过右键“存为常用语”加入。

**可选触发词只在受支持的独立标准 US 键盘布局下使用**：

1. 给一条无敏感内容的常用语设置触发词，例如 `cbqa`；在设置里开启“触发词快速粘贴”。
2. 按 **Win+空格**，选择独立的“英语（美国）— US”键盘。若列表没有该布局，先保持触发词关闭，仍可点击常用语粘贴。
3. 在普通权限的空白编辑框输入 `cbqa`，再按一次空格，应展开成完整正文。缩写前需要词边界，不能紧接其他字母、数字或下划线。

**微软拼音无论显示“中”还是“英”，都暂停自动展开。** US International、Dvorak 和无法确认的布局也会跳过。Enter、Tab 不触发替换；点击、滚轮、继续输入、快捷键或布局变化会取消排队中的替换。无需为了使用普通剪贴板和常用语点击粘贴而更改输入法。

## 5. 文本变换与导出

选中条目后按 **Ctrl+T**，可以做 JSON 格式化、编码转换、大小写或行处理；确认结果后再复制、另存为条目或覆盖原条目。

按住 **Ctrl** 点选多个条目，或用 **Shift** 连选，再按 **Ctrl+E** 导出。没有多选时导出当前结果；可选择 TXT、CSV、JSON 或 Markdown。导出文件写入当前数据目录；JSON 导出不是图片目录的完整备份。

## 6. 数据存在哪

打开 **托盘右键 → 关于**，查看实际 `ClawBoard数据.json` 路径。规则是便携优先：

| 情况 | 数据目录 |
|---|---|
| exe 所在目录可写 | exe 所在目录 |
| exe 所在目录不可写，例如普通权限运行于 Program Files | `%APPDATA%\ClawBoard\` |
| 从源码运行 | 源码根目录 |

图片在该目录的 `images/` 中，日志为 `crash.log`。安装方式和运行权限都可能影响可写性，因此应以“关于”显示的路径为准。不要为了自动粘贴而将整个程序改为管理员运行。

便携版会产生这些本地文件；开启“开机自启”还会写入当前用户的 `Software\Microsoft\Windows\CurrentVersion\Run` 中的 ClawBoard 项，关闭该选项会移除此项。安装版另外有安装登记和快捷方式。

## 备份、升级与迁移

1. 用 **Ctrl+Q** 或托盘菜单退出 ClawBoard。
2. 找到实际数据目录，把 **`ClawBoard数据.json` 和整个 `images/` 文件夹**复制到备份位置；已有的 `.bak`、`.bak.1`、`.bak.2` 也可保留。这些迁移备份不能代替自己定期备份。
3. 便携升级时，只替换原位置的 `ClawBoard.exe`，保留同层数据和 `images/`。若把新 exe 放到另一个子目录，它会从另一个数据位置启动，看起来像没有历史。
4. 换电脑或恢复备份时，先退出目标程序，再把 JSON 和图片目录放到目标实际数据目录，然后启动核对。不要让多个实例同时写同一份库。

安装包升级前也先备份；卸载默认保留数据，静默卸载也保留数据。已验证本机独立目录的静默安装与保留数据卸载，范围见 [Windows 验证记录](WINDOWS_VALIDATION.md)。

Python 与 C 版兼容共享 JSON 格式，但 C 版功能更少；切换实现前同样先退出并备份。旧 2.6.1 预览包与正式 v2.7.0 是不同构建。

## 7. 隐私设置

历史和设置是**明文 JSON**，图片是 PNG。列表打码只是显示遮罩，保存的原文及导出、备份仍需保护。

在设置中按自己的需要检查：

- 保持剪贴板私密标记识别开启；只有提供这些标记的来源才能靠标记跳过。
- 将不希望记录的应用或窗口加入忽略名单。
- 保持敏感显示打码；若希望识别后不保存，再开启“敏感内容跳过”。该跳过选项默认关闭，打码并不代表没有入库。
- 不要依赖识别规则保存密码安全。规则存在漏检，超长文本的邮箱识别也有扫描长度限制。
- 默认更新检查会联网访问 GitHub，可在设置关闭；关闭后仍可使用本地采集、搜索、变换和粘贴。检查更新只提示并跳转下载页。

## 8. 常见问题

**唤起快捷键没有反应。** 先从托盘打开设置，改用 `Alt+V` 或 `Ctrl+Alt+V`。程序会尝试候选组合，并在都注册失败时回退检测默认 `Ctrl+Shift+V`；以设置和提示中显示的实际组合为准。

**目标是管理员程序。** 普通权限 ClawBoard 会停止向更高权限目标自动发键；无法确认权限时也不自动发键。若内容已成功复制，在目标框手动按 `Ctrl+V`。目标拒绝焦点或输入时，也使用这一降级方式。

**触发词没有展开。** 先确认已升级到 v2.7.0、开关开启、输入位置不是 ClawBoard 面板本身，并且选的是独立标准 US 键盘。微软拼音切换到“英”仍不属于这个布局。也可直接点击常用语使用。

**面板找不到。** 先尝试唤起，再用托盘右键的“面板找不到了？重置位置”。主面板支持跨屏缩放；已经打开的独立弹窗并不代表都有相同的跨屏适配能力。

**正文首尾空白变化。** 默认粘贴时裁剪首尾空白，内部行的缩进保留；需要完整保留边缘空白时，在设置关闭这一选项。

## 9. 快捷键速查

只有唤起键是全局热键；其余在面板内使用。

| 快捷键 | 操作 |
|---|---|
| `Ctrl+Shift+V` | 显示 / 隐藏面板 |
| `↑` / `↓`、`Enter` | 选择、粘贴 |
| `Ctrl+1`…`Ctrl+9`、`Ctrl+0` | 粘贴当前列表第 1–10 项 |
| `Ctrl+F` | 搜索 |
| `Ctrl+Shift+Enter` | 纯文本粘贴 |
| `Ctrl+T` / `Ctrl+E` | 文本变换 / 导出 |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+=` / `Ctrl+-` | 调整用户缩放 |
| `Delete` | 删除选中项 |
| `Esc` / `Ctrl+Q` | 隐藏 / 退出 |

更多技术边界见 [Windows 验证记录](WINDOWS_VALIDATION.md)和[当前架构](REFACTOR.md)；历史版本变更见 [CHANGELOG](../CHANGELOG.md)。
