ClawBoard 2.6.1 · refactor-preview 重构预览包

这是重构分支的评估构建，程序版本号保持 2.6.1，不是正式 Release。
源码分支和完整提交号见 BUILD-INFO.txt。

快速开始（建议使用便携版）
1. 将整个 ZIP 解压到独立、可写的文件夹，先退出其它 ClawBoard 实例。
2. 双击 ClawBoard.exe。支持 Windows 10/11 64 位，无需安装 Python。
3. 默认 Ctrl+Shift+V 呼出或隐藏面板；从托盘菜单退出程序。
4. 本包不含用户数据。便携模式的数据文件 ClawBoard数据.json 与 exe 同层，图片位于同层 images 文件夹。移动时将它们一起保留。

保留已有数据
迁移前退出程序，备份原数据文件和 images，并保留原 exe。先用数据副本验证兼容和回退，再决定替换日常版本。本包不会自动定位、搬移其它安装的数据，也不会替换既有安装。主动载入的旧格式数据会在内存中迁移，首次保存前会备份原文件。

行为和限制
- 常规复制与粘贴支持中文。触发词自动展开仅对独立 English (United States) / US 键盘布局启用；中文输入法、微软拼音的“英”模式、其它或未知布局会保留输入并停用展开。
- 普通权限程序向管理员窗口自动输入时会保留剪贴板内容并提示手动 Ctrl+V；请先将焦点放在目标输入框。
- 主面板在 125%/150% 双屏验证过缩放往返，不代表所有独立弹窗及显示配置均已验收。

可选安装包
ClawBoard-2.6.1-refactor-preview-setup.exe 会写入安装目录、快捷方式和卸载登记，需要 Windows 权限确认。本机独立测试目录的静默安装、NO_SAVE 启动和保留数据卸载已通过，未在虚拟机验证交互式向导；已有日常版本时建议先用独立目录便携版。
卸载的数据删除确认默认“否”，静默卸载保留数据；只有交互式明确选择“是”才删除数据。卸载只清除指向本安装的自启动项。
